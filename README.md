# skill-s

סביבת עבודה בענן עבור Claude Code.

## כלים שמותקנים אוטומטית בכל סשן בענן
- **Teach** – מורה פרטי: `/teach <נושא>`
- **Trail-code (Graft)** – מפת קוד + זיכרון של מה שלמדתם (נשמר בתיקייה `.trail/`)
- **Codebase Memory MCP** – גרף ידע של הקוד ("מי קורא למי")
- **OpenMontage** – הפקת וידאו, בתיקייה `~/OpenMontage`
- **Graphify** – מפת ידע של הקוד, נשאלת במקום לקרוא קבצים: `/graphify .`
- **Scrollcraft** – בניית אתרים שזזים בגלילה: `/nateherk-design:scroll-craft`
- **GSD Core** – ניהול פרויקט גדול בשלבים עם זיכרון בין סשנים: `/gsd-new-project`, `/gsd-help`
- **rea-video** – פירוק סרטון: איך כל צילום נעשה ואיך לשחזר אותו: `rea-video decompose`
- **Claudex Loop** – Claude ו-Codex מתכננים ובודקים זה את זה (כרגע רק `claudex-route` פעיל, אין Codex)
- **landing30** (ערכה בתיקייה `kits/landing30`) – דף נחיתה לכל עסק ברשימה בפקודה אחת: `/build-all`
- **עיצוב אתרים:** frontend-design, UI/UX Pro Max, Taste Skill, Impeccable – עיצוב ברמה גבוהה ובדיקת "מראה של AI"
- **בדיקה לפני עלייה לאוויר:** site-launch-check (אבטחה, באגים, נגישות וחוק ישראלי), Trail of Bits static-analysis, claude-wcag-audit
