# landing30: דף נחיתה לכל עסק ברשימה, בפקודה אחת

ערכה מוכנה לבניית הרבה דפי נחיתה במקביל. כל עסק ב-`businesses.json` מקבל דף משלו, שנבנה על ידי תת-סוכן נפרד (Sonnet, במאמץ נמוך, ולכן זול). מקור: המדריך של IdanTech, "30 דפי נחיתה בפקודה אחת".

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `businesses.json` | רשימת העסקים. כרגע שתי דוגמאות; מוסיפים עסקים באותו מבנה |
| `BRIEF.md` | ההוראות שכל תת-סוכן קורא: מבנה הדף, פונטים, תמונות, עיצוב, ומה אסור להמציא |
| `.claude/agents/landing-builder.md` | תת-הסוכן שבונה דף אחד |
| `.claude/commands/build-all.md` | הפקודה `/build-all`: מריצה תת-סוכן לכל עסק, ובסוף כותבת סיכום וגריד תצוגה |
| `.claude/commands/upgrade.md` | הפקודה `/upgrade`: מוסיפה מחירון לדוגמה וטופס שפותח וואטסאפ |

## איך מריצים

1. פותחים את Claude Code **בתוך התיקייה הזו**, כי רק שם הוא מזהה את תת-הסוכן ואת הפקודות. אפשר גם להעתיק אותה לפרויקט אחר.
2. ממלאים את `businesses.json`.
3. מתחילים בשלושה עסקים:
   ```
   /build-all use only the businesses with id 1, 2 and 3
   ```
4. כשהכול עובד, מריצים על כל הרשימה: `/build-all`
5. צופים בכל הדפים בקובץ `sites/index.html`. הזמנים לכל דף נמצאים בקובץ `sites/summary.md`, ואת העלות רואים עם `/cost`.
6. שדרוג לדפים נבחרים: `/upgrade biz-01 biz-11`

## חשוב

- **התמונות לדפים מגיעות מ-Unsplash, Pexels ו-Pixabay.** ההגדרות של סביבת הענן חוסמות כרגע את האתרים האלה, ולכן הדפים ייצאו עם רקעים צבעוניים במקום תמונות עד שהם ייפתחו.
- **הוספתי כלל ל-BRIEF:** לא להשתמש בתמונות שמופיעות בהן נשים, ולהעדיף תמונות של מוצרים, כלים ומקומות.
- **המחירים שהפקודה `/upgrade` מוסיפה הם לדוגמה בלבד.** לפני ששולחים דף לעסק אמיתי, צריך להחליף אותם במחירים של העסק ולבדוק את רישיון התמונות.
- **Claude Code מריץ עד 20 תתי-סוכנים במקביל.** השאר נכנסים לתור.
- **עסקים מאותו תחום עלולים לקבל אותן תמונות.** כדאי לעבור על הגריד ולהחליף כפילויות.
- **הדפים לא נבדקו לנגישות, ואין בהם מדיניות פרטיות.**
- **עלות לדוגמה מהמדריך:** 30 דפים, בערך 2:20 דקות ו-4.10$.
